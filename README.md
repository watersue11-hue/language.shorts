# 무료 다국어 학습 숏츠 생성기 - 인트로/발음 옵션 버전

## 추가된 기능
- 인트로 카드 넣기 / 빼기 선택 가능
- 한국어 발음(한글 표기) 표시 선택 가능
- 테마 4개 선택 가능
- 표현 개수 선택 유지
  - 쇼츠: 1개~10개
  - 롱폼: 1개~50개
- 자동 표현은 최대한 겹치지 않도록 주제별 + 기본 표현 풀을 확장

## 직접 입력 형식
- 기본 3칸: 한국어 뜻 | 외국어 표현 | 짧은 설명
- 발음 포함 4칸: 한국어 뜻 | 외국어 표현 | 한국어 발음 | 짧은 설명

## 파일명 규칙
- intro / nointro
- pron / nopron


## 이번 추가 수정
- 자기소개뿐 아니라 공항/카페/음식점/여행/교통/숙소/학교/쇼핑/병원/비즈니스/DM 등 상황별 표현 세트를 더 풍부하게 확장
- 프랑스어/독일어/이탈리아어도 기본 표현만 있던 부분을 여러 상황으로 확대
- 주제 키워드 인식 범위를 넓혀 입력한 주제에 더 잘 맞는 표현 묶음을 우선 선택
